# Кодбук производных переменных — «Всероссийский опрос аспирантов»

Источник: `Аспиранты_массив.sav` (коды SPSS, 5007 строк x 276 колонок).
Очищенный датасет: `aspirants_clean.parquet` / `aspirants_clean.csv` (5007 строк x 329 колонок).

## Глобальные правила очистки

1. **Коды-отказы -> NA до любых расчётов.** Коды 98/99 переведены в NA только там, где метка значения в .sav подтверждает отказ («затрудняюсь»/«нет ответа»/«не могу оценить»/«не применимо»). Тем же правилом пойманы шкальные отказы с другими кодами: `Q1_r*` (6), `Q9_r*` (5), `Q18_r*` (5), `QPar2_r*` (7). **Контрпримеры, которые НЕ тронуты:** `QCitiz`=99 («Македония») и `QVuz`=99 (настоящий вуз) — это содержательные коды, глобальная замена 98/99 «в лоб» уничтожила бы 6 наблюдений.
   Затронуто колонок: 106, ячеек -> NA: 118.
2. **Структурные пропуски-фильтры не импутируются и не восстанавливаются** (блок S у 76 без руководителя; Q22/Q23 у не имеющих соответствующей работы; Q21_*/Q210_* по фильтрам занятости).
3. Исходные переменные в датасете сохранены под исходными именами, уже очищенные от кодов-отказов. Производные — snake_case, описаны ниже.
4. Переменная возраста в массиве **отсутствует** (нет ни возраста, ни года рождения) — в блоке D прокси: год обучения, перерыв после магистратуры.

## Переменные «не для моделей»

- `valid_q27`, `valid_q28` — самооценка шансов защиты и планируемые сроки: измерены одновременно с исходом и правдоподобно являются его следствием (overcontrol). Только проверка конвергентной валидности целевой.
- `Q210_*` (области работы вне вуза) — только описательно, в модель не входят.
- Встроенные `field_1`–`field_6` — битые (сливают категории 7–8 в референс), не использовать; вместо них `field_d1`–`field_d8`.
- `vuz_id` — только для кластеризации / случайного интерсепта по вузу.
